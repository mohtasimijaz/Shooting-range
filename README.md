# Range — Arcade pistol shooting hall

First-person 3D shooting range in the browser. Pistols, timed waves, combo scoring.

## Play locally

```bash
npm install
npm run dev
```

Open the Vite URL, click **Play**, then click the hall to lock the mouse.

## Controls

- Mouse look · Left click fire
- `R` reload · `1` / `2` / `3` or wheel switch pistols
- `A` / `D` strafe on the firing line
- `Esc` pause / unlock mouse

## Publish (GitHub Pages)

After you confirm local play:

1. Create a public GitHub repo named `shooting-range`.
2. Push `main`.
3. Repo **Settings → Pages → Source: GitHub Actions**.

Play URL: `https://<your-github-username>.github.io/shooting-range/`
